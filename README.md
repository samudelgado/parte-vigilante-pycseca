# Parte Vigilante · PYCSECA

App web para hacer el parte diario del vigilante desde el móvil, sin instalar nada.

- Datos del servicio: número, fecha, turno, cliente y dependencia.
- Vigilantes de seguridad con nombre y número TIP.
- Novedades por hora y medidas adoptadas / observaciones.
- Tres firmas con el dedo: vigilante, cliente y jefe de servicio.
- Partes guardados en el propio teléfono, imprimir / guardar en PDF y copia de seguridad en JSON (exportar e importar).

## Uso en iPhone

Abre la página publicada en Safari, toca Compartir y «Añadir a pantalla de inicio».
Se abre a pantalla completa como una app. Los partes se guardan en el propio teléfono.

## Archivos

- `index.html`: la app completa en un solo archivo, sin dependencias.
- `apple-touch-icon.png`: icono para la pantalla de inicio del iPhone.
